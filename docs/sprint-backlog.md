# Sprint 1 Backlog

*Sprint Goal:** Establish the foundation of the Team Task Board by creating project documentation and core task management features.

**Sprint Dates:** 09/17/2026 → 09/24/2026

---

## User Stories

Use the format: *"As a [user type], I want to [action] so that [benefit]."*

Each story should have:
- **Story Points** (1, 2, 3, 5, or 8 — use Fibonacci scale)
- **Priority** (High / Medium / Low)
- **Status** (To Do / In Progress / Done)
- **Acceptance Criteria** (how will we know it's done?)

---

### Story 1

**Title:** Create Definition of Done Document

**User Story:**
> As a team member, I want a documented Definition of Done so that everyone understands when work is considered complete.

**Story Points:** 2
**Priority:** High
**Status:** To Do

**Acceptance Criteria:**
- [ ] Definition of Done document exists in the docs folder
- [ ] Document contains at least 4 completion criteria
- [ ] Team members can easily read and understand the criteria 

---

### Story 2

**Title:** Add New Tasks to the Board

**User Story:**
> As a team member, I want to add tasks to the board so that project work can be tracked and organized.

**Story Points:** 5
**Priority:** High
**Status:** To Do

**Acceptance Criteria:**
- [ ] New tasks can be added to the board
- [ ] Each task contains a title and description
- [ ] Added tasks appear in the backlog list

---

### Story 3

**Title:** Update Task Status

**User Story:**
> As a team member, I want to change the status of a task so that progress can be tracked throughout the spring

**Story Points:** 3
**Priority:** Medium
**Status:** To Do

**Acceptance Criteria:**
- [ ] Tasks can be marked as To Do, In Progress, or Done
- [ ] Status changes are visible on the board
- [ ] Updated status is retained after saving
