# Definition of Done

> A story is **Done** when ALL of the following criteria are met.
> This list should be agreed upon by the whole team before Sprint 1 begins.

---

## Code Quality

- [ ] Code has been reviewed by at least one other team member
- [ ] Code follows project standards and contains clear, readable comments where needed

## Testing

- [ ] All acceptance criteria have been manually verified
- [ ] No known bugs introduced by the change

## Documentation

- [ ] README or project documentation has been updated if necessary

## Version Control

- [ ] Feature branch has been merged to main through a Pull Request
- [ ] Commit messages follow the Conventional Commits format
